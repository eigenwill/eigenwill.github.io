从文章到发布，三步就好

日常发布
  1. 01

    写好文章

    下载并解压目录模板，将 my-new-post/ 改成文章名。正文写在 index.md，图片放在同目录的 images/，正文引用如 ![说明](./images/result.png)。

  2. 02

    上传并提交

    点击「上传文章目录」，在 GitHub 登录后拖入整个文章文件夹。确认上传列表保留 文章名/index.md 与 文章名/images/…，再点击 Commit changes 提交到 master。不要直接上传 ZIP 或把 index.md 单独放进文章根目录。

  3. 03

    等待自动发布

    GitHub Actions 会构建博客。打开「发布状态」，最近一次流程显示绿色后，刷新博客查看文章。通常需要几分钟。

发布前，检查一下

仅在本地读取

选择完整文章目录，预检正文、目录名与常见图片引用，不上传文件。

选择文章文件夹

例如 my-new-post/，内含 index.md 与 images/

正文预检上限 2 MB。只检查常见行内图片语法，复杂写法与最终发布结果以 GitHub 构建为准。
